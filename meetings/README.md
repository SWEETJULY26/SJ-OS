# Meetings

Leadership and strategic meeting logs, one file per meeting: `YYYY-MM-DD-<slug>.md`.

Started 2026-08-06 with the Leadership Business Review; leadership wants these tracked going forward. Source of truth for the raw transcript is Fireflies (ID in each file's header); these files carry the interpreted version: headlines, decisions, and action items.

What goes here: leadership business reviews, check-ins with strategic content, planning workshops. What doesn't: routine standups and vendor calls, which flow through the bridge skills into Asana, not here. Decisions that matter beyond the meeting also get an entry in `decisions/log.md`; the meeting file links context, the decisions log carries the why.
