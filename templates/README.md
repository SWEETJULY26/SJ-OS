# Templates

Root-level templates: things reused across more than one skill or system. If a template only ever gets used by one skill, it stays in that skill's own `references/` folder (e.g. `asana-pd-manager/references/task-description-templates.md`) — don't move it here just to fill this folder. This is for genuinely cross-cutting stuff: a format multiple skills draft into, or a structure Alvin reuses by hand across projects.

Nothing lives here yet. Add a template when a second skill (or a manual workflow) needs the same shape a first one already uses — that's the signal it belongs at this level instead of buried in one skill's references.
